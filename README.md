📚 Bibliothe – Library Management System

Bibliothe is a Java-based library management system developed as a collaborative academic project.
Its goal is to help libraries efficiently manage books, users, and reservations through a structured and reliable system connected to a relational database.

🚀 Features
📖 Book Management

Add, update, delete, and view books

Track book availability

Organize books efficiently within the library

👤 User Management

Register and manage library members

Store and update user information

Link users to their reservations

🔄 Reservation System

Allow users to reserve available books

Manage active and completed reservations

Ensure better book circulation and availability

🗄️ Database Integration

SQL scripts for database creation and data insertion

Structured relational design for consistency and reliability

Easy database migration and setup

⚙️ System Structure

Clean and organized Java project architecture

Separation between logic, database, and execution scripts

Batch files for easy execution on Windows

🛠️ Technologies Used

Java

SQL (relational database)

JDBC (database connectivity)

Batch scripting (Windows execution)

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/zaineb58/bibliothe.git


Import the project into your Java IDE (IntelliJ, Eclipse, NetBeans)

Execute the SQL scripts to create and populate the database

Configure database connection parameters if needed

Run the application using the provided batch file or directly from the IDE
